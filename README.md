# 🔐 Interface de Login do Trello

Projeto desenvolvido para reproduzir uma **interface de login inspirada no Trello**, utilizando HTML, CSS e JavaScript.

O objetivo foi praticar a construção de interfaces web, organização de elementos, estilização com CSS e criação de interações e animações com JavaScript.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* SVG
* Flexbox
* Manipulação do DOM
* Animações e transições

## ✨ Funcionalidades

* Interface de login inspirada no Trello
* Campo para e-mail
* Campo para senha
* Botão de login
* Login visual com:

  * Google
  * Microsoft
  * Apple
  * Slack
* Elementos gráficos decorativos
* Logos e imagens em formato SVG
* Animações das imagens decorativas utilizando JavaScript
* Layout organizado e responsivo

## 🎨 Interface

A interface foi construída com um formulário centralizado e elementos gráficos posicionados ao redor da tela.

Foram utilizadas imagens relacionadas ao ecossistema visual do projeto, incluindo:

* Logo do Trello
* Atlassian
* Analytics
* Interactive
* Google
* Microsoft
* Apple
* Slack

As imagens decorativas possuem movimentação utilizando JavaScript para deixar a interface mais dinâmica.
